Install

Choose your platform

Download PrtScr and follow the steps below. It runs from the system tray on Windows and Linux, or the menu bar on a Mac.

Windows

Windows 10 (2004) or 11, 64-bit
PrtScr-setup.exe
  1. Run PrtScr-setup.exe. It installs for you alone, with no administrator prompt.
  2. If SmartScreen warns you, choose More info, then Run anyway. The installer is not signed yet.

  3. Keep screen recording ticked if you want it. Setup downloads PrtScr's own checked copy of FFmpeg for it, and Microsoft's WebView2 only if Windows lacks it.
  4. Press PrtScr. PrtScr waits in the system tray.

macOS

macOS 13 or later, Apple silicon or Intel
PrtScr-macos.dmg
  1. Open PrtScr-macos.dmg and double-click Install PrtScr.
  2. If macOS cannot verify it, click Done, open System Settings → Privacy & Security, click Open Anyway and confirm. PrtScr is not notarized yet.

Questions

Good to know

What does it cost?

Nothing. There is no account, no subscription and no watermark.

Does PrtScr upload my captures?

Not by default. Captures are stored in a local library. You can choose to share them or configure backup and sync under Settings → Library and files. Anonymous error reporting is separately opt-in and does not send captured content.

Where can it back up or sync to?

A local folder, a network share, a mounted NFS folder, SFTP, WebDAV, FTP or FTPS, S3-compatible storage, OneDrive, Google Drive or Dropbox, as many as you like. Connect two computers to the same place and captures, edits and deletions travel both ways. Competing edits are kept as copies, never overwritten.

Does local AI search send my captures anywhere?

No. It runs an AI model, Google’s EmbeddingGemma, on your own computer, with no account and no internet connection. Switch it on in Settings → Library: the model downloads once, about 320 MB, and PrtScr reads your captures into it while you are away from the computer. Nothing you capture or search for leaves your computer, and switching it off stops it reading anything more.

Can my coding agent use PrtScr?

From the next release, yes. Claude Code, Codex and other agents that run on your computer can take a screenshot, capture a whole page, search and read your captures, change settings and record the screen, through a local MCP connection. Add it under Settings → Library → Coding agents. PrtScr sends nothing itself; what an agent is given goes wherever that agent sends it, which for most is its AI service.

Where can it read text and search by meaning?

Reading text uses your system’s own recognition, built into Windows and macOS; on Linux it uses tesseract, which the installer offers to add. Settings chooses the language to read, and the editor can read a picture again in another one. Local AI search runs on Windows, on Linux and on Macs with Apple silicon; on an Intel Mac it says it cannot run there.

How does it update?

It downloads the next version in the background and switches to it when you choose Restart to update, when you are away, or the next time it starts. Settings can turn that off, and Check for updates is always there.

Does it send anything about me?

Only if you turn on Send anonymous error reports. A report says what failed and where in PrtScr, with names, folders and e-mail addresses taken out, and nothing you captured or copied. Settings lists each one exactly as it was sent.

Does it work on Linux?

Yes, as a preview. Screenshots, the library and the editor work on Omarchy and other Hyprland setups, GNOME and KDE, on Wayland or X11, on 64-bit x86. Not there yet: screen recording, picking a window to capture outside Hyprland, and backup locations that need a password or a sign-in.

Something went wrong. What should I send?

Open an issue saying what you did and what happened. The log is at %LOCALAPPDATA%\PrtScr\logs\app.log on Windows, ~/Library/Application Support/PrtScr/logs/app.log on a Mac and ~/.local/share/PrtScr/logs/app.log on Linux.
